# Working on this repo

SIVED is the Super Intelligence Virtual Editting Desk. The public history starts at one commit.

A change is not done while it exists only on the machine that wrote it.

Commit it on a branch. Push the branch. Open a pull request into `main`. Leave that pull request open. A person approves it and merges it. `main` on GitHub is the copy that counts.

Do not leave the change in the working tree. Do not leave the branch unpushed. Do not merge the pull request. Do not turn on auto-merge. Do not force-push `main`.
