# Authors

You are a customer of one editor. Access is that editor's Patreon membership. You upload a manuscript, and a run is included. This desk does not charge you. A human edit is arranged with that editor, off this desk.

This desk does not charge, hold, or invoice a human edit.

## Become a customer

Open the editor's page. The address looks like `/e/{id}`. The editor puts that link on their site. The page names the practice and lists the personas.

On a real desk, press **Continue with Patreon**. The desk asks that editor's Patreon client whether you are an active member of their campaign. Verify your email at Patreon before you do. A typed name and email is not access. Patreon has to show a current entitlement for that campaign: an entitled amount, or a currently entitled tier. If the membership is not active, the email is not verified, or Patreon cannot confirm it, the desk refuses the login and closes the session. An editor, owner, or other local login is not attached to Patreon from this button.

You then land on **Your manuscripts**. Come back the same way. The desk asks Patreon again when the last confirmation is old. That Patreon account cannot join a second editor. If it already belongs to one, the page says "author already belongs to an editor".

On a local desk or a demo, the page asks for your name and email and you press **Become a customer**. That path does not ask Patreon. Leave dev and demo sign-in off before a real author uses the page. The built-in author is `author@example.com`, already a customer of `owner@example.com`. You can also open the sign-in page, choose that email, and press **Continue**.

Press **Sign out** in the header when you are done. The desk does not email you an invite. When your editor has connected mail, a manuscript that is ready or did not finish is sent to your sign-in email. The contact email on Profile is not that address.

## Profile

**Profile** is in the header. Set your name, a contact email, and a phone. The sign-in email stays the account. That contact email is not where manuscript notices are sent. Saving does not change which editor you belong to. Profile does not open a manuscript. Manuscripts stay closed until Patreon confirms the membership.

## Submit a manuscript

With nothing sent yet, **Your manuscripts** names what this editor offers. Press **New manuscript**. Choose the persona. A run is included with your membership. After you send one, the desk opens on that manuscript. The shelf lists the others.

Enter a title, genre, and audience. Three fields are optional:

| Field | What it does |
| --- | --- |
| Comps | Books or stories this one sits beside. The editor can use this when deciding whether to offer a human edit. |
| Do not change | The only text the letter may mark locked. Put constraints here, such as "The river does not return." |
| Focus | Adds one extra diagnosis on the point you name. The other passes still run. |

Upload the manuscript file and press **Submit**.

The desk turns the file into text and stores that text. The letter is written from the text. Accepted files are Word (`.docx` and legacy `.doc`), PDF, RTF, OpenDocument (`.odt`), HTML, EPUB, Markdown, and plain text (`.txt`, `.text`, `.md`, `.markdown`). The file must be 8 MB or smaller and must contain text. A scanned PDF is refused. Save a legacy `.doc` as `.docx` if the page says it could not be read.

The manuscript page then shows `queued` and the word count. This desk does not charge you.

A manuscript over the persona's word limit, or over the length this desk will run, is refused.

## After you submit

The status is `queued`. When the run is finished the status is `ready`. The page shows the documents the agent stored. The editor's agent runs its skills and its code.

| Heading | What it is |
| --- | --- |
| letter | The developmental letter, when the agent stored one. It diagnoses the manuscript. It does not rewrite it. |
| compendium | A facts file for the project, when the agent stored one. |
| readback | A canon preview, when the agent stored one. |

The default agent stores a letter, a compendium, and a readback. The letter's headings are promise and genre fit, plot and structure, character, and stakes and pacing. A focus you entered adds one more diagnosis.

If every page says the desk is a demo, **Submit** stores the manuscript and marks it `ready` with a note that no letter was written. A demo does not call a model.

## Ask for a human edit

Press **Ask this editor to work on it**. The editor sees it as a manuscript they may want to take. A human edit is arranged with that editor, off this desk.

Use **Messages** and **Send** to talk about that work. The thread stays on the manuscript page.

## If the page refuses the file

| The page says | What to do |
| --- | --- |
| upload a manuscript file | Choose a file before you submit. |
| upload a manuscript as .txt, .md, .docx, .doc, .odt, .rtf, .pdf, .html, or .epub | Use one of the accepted types. |
| this file has no manuscript text | The file opened but had no prose. Export the text and upload that. |
| manuscript file is over 8 MB | Send a smaller file. |
| this PDF has no extractable text. Upload a .docx or .txt file instead. | The PDF is a scan or an image. Upload a `.docx` or `.txt` file. |
| save .doc files as .docx and upload that | Upload a `.docx` instead of the older Word file. |
| manuscript is over this persona's word limit | Shorten the manuscript or ask the editor to raise the limit. |
| this manuscript is over the length this desk will run | Shorten the manuscript. |
| title, genre, and audience are required | Fill those three fields. |
| this editor is not taking customers | The practice is suspended, or the link is an assistant's page. Use the practice editor's link. |
| sign in with Patreon | Open the editor's page and press **Continue with Patreon**. |
| This editor has not connected Patreon. | That editor has not saved their own Patreon client yet. |
| Patreon did not authorize this login | Start again from the editor's page. |
| that Patreon login expired | Start again. That link lasts about ten minutes and works once. |
| verify your email at Patreon before signing in | Confirm the email on the Patreon account, then try again. |
| Patreon did not share an email | Allow Patreon to share the account email, then try again. |
| this Patreon account is not an active member of this editor's campaign | Join that editor's Patreon campaign, then try again. |
| this Patreon membership is not active | The membership ended, or Patreon no longer shows an entitlement. |
| sign in with Patreon again | Press **Continue with Patreon**. The stored login is no longer enough. |
| Patreon could not confirm this membership | Patreon did not confirm it. Access stays closed. |
| Patreon could not be reached | The desk could not reach Patreon. Access stays closed. |
| that email already has another role | That email is already an editor, an admin, the owner, or a local account. |
| author already belongs to an editor | That Patreon account is already a customer of an editor. |
